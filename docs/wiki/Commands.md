# 命令与权限

## 玩家命令

| 命令 | 用法 | 说明 |
|---|---|---|
| `/register`（别名 `reg`、`r`） | `/register <密码> <确认密码>` | 首次注册（仅离线玩家，注册成功后自动登录） |
| `/login`（别名 `l`） | `/login <密码>` | 登录（仅已注册离线玩家） |
| `/changepassword` | `/changepassword <旧密码> <新密码>` | 修改密码（需已登录） |

## 管理命令

| 命令 | 用法 | 说明 |
|---|---|---|
| `/multiauth reload` | — | 重载配置 + 语言 + proxy 模式 |
| `/multiauth status` | — | 查看插件状态（版本/数据库/模式/Mojang API/玩家统计） |
| `/multiauth backup` | — | 手动备份数据库 |
| `/multiauth migrate <type>` | `sqlite \| mysql` | 数据库迁移 |
| `/multiauth info [player]` | — | 查看账号信息（玩家查自己；管理员可查任意玩家） |
| `/multiauth unregister <player>` | — | 强制删除离线玩家账号 |

Velocity 端管理命令统一为 `/vmultiauth`（控制台专用），与 Spigot 端 `/multiauth` 共享同一套子命令与执行逻辑。

## 权限节点

| 权限节点 | 默认 | 说明 |
|---|---|---|
| `multiauth.admin` | OP | 管理命令（reload/status/backup/migrate/unregister）及 `info` 查询任意玩家 |
| `multiauth.info` | 所有玩家 | `info` 查询自己的账号信息 |

## /multiauth info 行为

`info` 对正版与离线玩家均可用，无参数时查询目标默认为执行者自己：

| 执行者 | `info`（无参数） | `info <玩家>` |
|---|---|---|
| 管理员玩家 | 查询自己 | 查询任意玩家 |
| 管理员控制台 | 提示用法 | 查询任意玩家 |
| 普通玩家 | 查询自己 | 提示"只能查询自己的信息" |

输出内容（正版 / 离线结构一致，公共部分 + 类型专属部分）：

- **公共**：玩家名、UUID、在线状态、最后 IP、地理位置
- **离线账号**：注册时间、最后登录
- **正版玩家**：最后登录、第一次进入（历史玩家记录显示"未知"）
- **登出地点**（仅管理员可见）：世界名 + 坐标，未记录时显示"未知"
- **关联账号**（多账号检测）：按玩家最近一次登录 IP 归因，反查该 IP 下的全部账号（离线账号表 + 正版玩家表合并去重），在线账号显示绿色、离线白色。管理员始终可见；普通玩家仅当配置 `auth.notify-other-accounts` 开启时可见（与登出地点同级）。玩家更换 IP 后，新关联集合即按新 IP 反查得到的列表

## 多账号检测

参考 AuthMe 归属逻辑，按**最近一次登录 IP** 归因账号（注册 IP 仅存不用；玩家每次登录都会覆盖更新 last_ip）：

- 登录成功时（正版进服 / 离线登录 / 注册 / 会话恢复 / 跨服同步）自动向玩家提示同 IP 的其他账号，由配置 `auth.notify-other-accounts` 控制（唯一真源，默认关闭；Velocity 端无独立配置项，info 展示从共享 AuthConfig 读取同一字段）
- `info` 命令展示关联账号，可见性同上：开关开启时普通玩家可见，否则仅管理员可见

## Mojang API 状态取值

| 状态 | 含义 |
|---|---|
| `正常` | API 服务已启用且可访问 |
| `宕机` | 全部 API 不可达（含冷却期快速失败），仅放行有离线历史记录的玩家 |
| `未启用` | proxy=true 的 Spigot 端不做 API 调用 |
| `未知` | 服务未初始化 |
